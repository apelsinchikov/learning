# Спецификация: конфиденциальность

## Purpose
Страница политики и обязательства по данным пользователей.

## Requirements

### Requirement: Страница политики
Сайт SHALL содержать статическую страницу `public/privacy.html`, доступную без
JavaScript и открытую по ссылке из подвала главной страницы.

#### Scenario: Проверка владельцем домена и Google
- **WHEN** страницу открывает проверяющий Google
- **THEN** в HTML есть ссылка на политику на главной и сам текст политики

### Requirement: Содержание политики
Политика SHALL описывать: какие данные собираются (email, имя, прогресс), зачем,
третьи стороны (Supabase, Google, Яндекс, GitHub Pages), хранение в браузере,
сроки, права пользователя, дети и контакт для обращений. Для Google SHALL
присутствовать заявление о соответствии Google API Services User Data Policy
(Limited Use).

#### Scenario: Запрос на удаление
- **WHEN** пользователь пишет на контактный адрес
- **THEN** политика описывает, что данные будут удалены

### Requirement: Подтверждение владения доменом
В `public/` SHALL лежать HTML-файл подтверждения Google Search Console, чтобы
домен оставался подтверждённым.

#### Scenario: Деплой
- **WHEN** сайт собирается
- **THEN** файл `google6b14ffeb5266d7f6.html` попадает в корень сайта
