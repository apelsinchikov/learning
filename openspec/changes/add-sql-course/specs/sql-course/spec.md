## ADDED Requirements

### Requirement: Структура курса SQL
Курс SQL SHALL состоять из 28 уроков в 7 главах и песочницы. Идентификатор
каждого урока SHALL начинаться с `sql-`. Каждый урок SHALL содержать сюжетную
сцену, теорию с блоком «Зачем», задачу, три подсказки (для задач-запросов)
и улику для блокнота.

#### Scenario: Урок без объяснения «зачем»
- **WHEN** в уроке нет блока «Зачем»
- **THEN** тест структуры курса падает

### Requirement: Только чтение
Запросы ученика SHALL выполняться в базе, открытой только для чтения. Курс
SHALL NOT содержать INSERT, UPDATE, DELETE и DDL.

#### Scenario: Попытка изменить данные
- **WHEN** ученик выполняет `DELETE FROM guests`
- **THEN** запрос не выполняется, показано сообщение «Менять данные нельзя»

### Requirement: Проверка по результату
Ответ SHALL проверяться сравнением таблицы результата с эталоном: строки как
мультимножество, порядок — только если урок его требует, имена колонок — только
если урок их требует. Подсказка о расхождении SHALL NOT раскрывать сам ответ.

#### Scenario: Тот же результат другим запросом
- **WHEN** ученик получает ту же таблицу иным, но верным запросом
- **THEN** ответ принимается

### Requirement: Человеческие ошибки
Ошибки базы SHALL показываться на русском с подсказкой: похожее имя колонки или
таблицы, опечатка в ключевом слове, объяснение про `WHERE` и `COUNT`.

#### Scenario: Опечатка в имени колонки
- **WHEN** ученик пишет `fullname`
- **THEN** подсказка предлагает `full_name`

### Requirement: Временный пароль
Пока курс закрыт, на странице курса SHALL показываться форма пароля. Пароль
общий, не зависит от аккаунта и прогресса. После ввода верного пароля доступ
запоминается в этом браузере. Вкладка «SQL» SHALL показывать замок, пока доступ
не открыт.

#### Scenario: Верный пароль
- **WHEN** ученик вводит верный пароль
- **THEN** открывается курс, замок на вкладке исчезает

#### Scenario: Неверный пароль
- **WHEN** ученик вводит неверный пароль
- **THEN** курс остаётся закрытым, показано «Пароль не подходит»

### Requirement: Улики и шпаргалка
Блокнот SHALL пополняться уликой после каждого решённого урока, а шпаргалка —
конструкциями из решённых уроков.

#### Scenario: Решён урок
- **WHEN** ученик решил урок
- **THEN** улика этого урока появляется в блокноте
