## ADDED Requirements

### Requirement: Вкладки курсов
В шапке SHALL быть вкладки «OpenAPI» и «SQL». Курс OpenAPI SHALL открываться по
адресу по умолчанию. Курс SQL SHALL открываться по адресам, начинающимся с `#/sql`.
Код курса SQL SHALL загружаться только при его открытии.

#### Scenario: Переключение курсов
- **WHEN** ученик нажимает вкладку «SQL», а затем «OpenAPI»
- **THEN** страница возвращается к курсу OpenAPI на том же уроке

### Requirement: Возврат после входа
Перед уходом на вход через Google или Яндекс сайт SHALL запоминать адрес курса SQL
и после возврата открывать его.

#### Scenario: Вход из курса SQL
- **WHEN** ученик входит, находясь на `#/sql/sql-where`
- **THEN** после возврата открыт тот же урок
