# Изменение: курс «SQL: тайна отеля „Перевал“»

## Зачем
Рядом с курсом OpenAPI нужен второй курс — по SQL (Postgres), в формате детектива.
Ученик — архивариус отеля, отрезанного метелью: он помогает инспектору найти вора,
а каждая новая конструкция SQL появляется как решение препятствия в сюжете.
Курс самодостаточный: в нём есть полный урок «Как читать базу» (таблицы, PK/FK),
хотя похожий материал есть в уроке 19 OpenAPI. Так курс можно проходить отдельно.

## Что меняется
- Новая вкладка «SQL» в шапке рядом с «OpenAPI». Адреса в хеше: `#/sql`,
  `#/sql/<id урока>`, `#/sql/sandbox`. Адрес по умолчанию (`#/`) остаётся курсом OpenAPI.
- 28 уроков в 7 главах и песочница. В уроке: сюжет, теория с блоком «Зачем это нужно»,
  запускаемые примеры, задача, лесенка из трёх подсказок, улика в блокнот дела.
- Postgres работает в браузере (PGlite, WebAssembly), подгружается с CDN только при
  открытии курса. Вставок и изменений данных в курсе нет: база только для чтения.
- Проверка по результату запроса (таблица сравнивается с эталоном), а не по тексту.
  Ошибки базы переводятся на человеческий язык.
- Прогресс сохраняется как у OpenAPI: сначала локально, у вошедших ещё и в Supabase.
- **Временный** доступ: курс закрыт общим паролем (см. спецификацию). Это нужно,
  чтобы показать готовую работу, но не пускать бета-тестеров, у которых доступ только к проду.

## Влияние
- Новые спецификации: `sql-course`.
- Изменяемые: `navigation-and-layout` (вкладки курсов), `progress-saving`
  (прогресс второго курса).
- Supabase: новая таблица `course_state` (`supabase/course_state.sql`) — её нужно
  выполнить один раз в SQL Editor. Без неё курс работает, но «текущий урок» не
  сохраняется в облаке. Уроки SQL лежат в существующей `lesson_progress`
  с идентификаторами `sql-...`.
- Код OpenAPI-курса: `main.js` (маршрутизация по хешу, ленивая загрузка курса SQL),
  `Header.js` (вкладки), `cloudStore.js` (игнорирует строки `sql-...`).
- Новых зависимостей в `package.json` нет: PGlite грузится с CDN во время работы.
  Следующий шаг — поставить `@electric-sql/pglite` как зависимость и отдавать его с сайта.

## Ограничения
- Пароль проверяется на клиенте. Это защита от случайных заходов, а не безопасность:
  сайт целиком клиентский, и хеш пароля виден в коде.
- Если CDN недоступен, запросы не выполняются; курс сообщает об этом и предлагает повторить.
