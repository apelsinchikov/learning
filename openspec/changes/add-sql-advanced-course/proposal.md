# Изменение: курс «SQL Advanced», схема базы и окно-подсказка «Повторить»

## Зачем
Нынешний курс SQL («Тайна отеля „Перевал“») заканчивается подзапросами и `CASE`.
Системному аналитику уровня middle нужно больше: собирать данные из нескольких
таблиц под метод API, писать читаемые запросы (`WITH`, `CASE`, `EXISTS`),
проектировать таблицы, ключи и представления, понимать, чем рабочая база отличается
от хранилища для отчётов (на примере ClickHouse), и просить у разработчика индекс.
Это не курс по аналитике данных и не по разработке, поэтому в нём нет оконных
функций, `UPDATE`/`DELETE`, транзакций и блокировок. Базовую теорию курс не
повторяет, но ученик должен в один клик найти нужное место базового курса.

## Что меняется
- Новая вкладка и курс «SQL Advanced» (`#/sql-advanced`): 5 глав, 27 уроков и
  песочница. Курс открыт всем.
- Новая база «Перевал: сезон» с бронями, оплатами и услугами за год. Данные
  создаются детерминированно.
- Движок запросов получает режим записи для уроков про таблицы и ограничения:
  `CREATE TABLE`, пробные вставки, `EXPLAIN`. Все изменения живут только внутри
  одного запуска и откатываются, база между запусками всегда исходная.
- Схема базы всегда под рукой: вкладка «Схема» и широкое окно с ER-диаграммой,
  построенной автоматически, для состояния базы текущего урока.
- Окно-подсказка «Повторить» (выдвижная панель справа): показывает урок другого
  курса, не уводя ученика с текущей страницы. Сначала коротко (шпаргалка), по
  кнопке полностью (теория без задачи).
- В уроках появляются ссылки на базовые уроки: блок «Вспомните», ссылки в тексте,
  кнопки в подсказках и в сообщениях об ошибках.
