# Изменение: открыть курс SQL и отмечать прочитанные уроки

## Зачем
Курс SQL готов, закрытый доступ по паролю больше не нужен. Кроме того, в курсе
OpenAPI теоретический урок получает галочку, когда его прочитали. В SQL галочку
давала только решённая задача, и ученик не видел, что уже прошёл.

## Что меняется
- Убрать временный пароль: экран ввода, проверку, замок на вкладке «SQL».
- Урок SQL получает отметку «прочитано», когда ученик дошёл до задачи и побыл
  на ней пару секунд, либо нажал «Следующий урок».
- В сайдбаре у решённого урока зелёная галочка, у прочитанного — светлая.
- Счётчик в шапке считает пройденные уроки (прочитанные и решённые).
- Блокнот улик и шпаргалка по-прежнему пополняются только решёнными уроками.

## Влияние
- Затронутая спецификация: `sql-course` (удаляется требование «Временный пароль»,
  добавляется «Отметки прохождения»).
- Данные: поле `read` у урока уже есть в модели прогресса, миграции не нужны.
- Код: `src/sql/views/nav.js`, `src/sql/sqlApp.js`, `src/sql/views/task.js`,
  `src/components/{CourseTabs,Header,App}.js`, `src/main.js`; удалены
  `src/sql/gate.js`, `src/sql/views/gate.js`.
