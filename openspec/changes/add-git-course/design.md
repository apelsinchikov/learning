# Дизайн: курс «Git и проект»

Для кого: аналитик без опыта работы с git. Тон: короткие шаги, у каждого шага
понятно «зачем» и «что должно получиться».

## Сквозной сценарий
Ученик создаёт настоящий репозиторий и проходит с ним весь курс. Курс не может
выполнить git в браузере, поэтому все команды ученик запускает у себя, а курс
подставляет в них его значения и сверяет вставленный вывод.

## Состав (12 уроков, 4 главы)

### Глава 1. Подготовка
1. `git-why` — что такое проект, git и GitHub; зачем история, откат, работа вдвоём
2. `git-account` — аккаунт GitHub; почему безопасность важна (2FA, токены, секреты)
3. `git-setup` — установка git, имя и почта в `git config`, вход в GitHub из терминала или VS Code

### Глава 2. Проект на GitHub
4. `git-repo` — создаём репозиторий (публичный, с README) и смотрим, что создалось
5. `git-branches` — ветка `develop` из `main`: что такое ветка и зачем две
6. `git-protect` — защита `main`: изменения только через pull request

### Глава 3. Работа на компьютере
7. `git-clone` — клонируем проект; что внутри, `git remote -v`, `git status`
8. `git-first-commit` — переходим в `develop`, первый («init») коммит, `git pull`
9. `git-add-commit-push` — файл, `status`, `diff`, `add`, `commit`, `push` в `develop`; проверка защиты `main`

### Глава 4. Pull request
10. `git-pr` — pull request `develop` → `main`, как читать diff (вкладка Files changed)
11. `git-merge` — слияние, способы слияния, обновить `main` у себя
12. `git-final` — шпаргалка команд и итоговый тест

## Профиль «Мой проект»
Поля: логин GitHub, имя репозитория, имя, почта, система (Mac / Windows),
способ работы (Терминал / VS Code). Хранится в `localStorage`
(`git-profile-v1`). Почта и имя в облако не уходят.
- В текстах уроков: `{{login}}`, `{{repo}}`, `{{name}}`, `{{email}}`.
  Пока значение не введено, показывается заметная заготовка `<ваш-логин>`.
- Значения проверяются: логин `[A-Za-z0-9-]` до 39 символов, репозиторий
  `[A-Za-z0-9._-]` до 100 символов. Имя и почта подставляются в команды в
  одинарных кавычках: автор пишет `'{{name}}'`, а одинарная кавычка внутри
  значения экранируется как `'\''`. Так команду можно безопасно скопировать.
- Сочетания клавиш: `[[key:mod+shift+p]]` рисуется как `⇧⌘P` на Mac и
  `Ctrl+Shift+P` на Windows. Панель Source Control в VS Code: `⌃⇧G` на Mac,
  `Ctrl+Shift+G` на Windows (по документации VS Code).
- Терминал: на Mac «Терминал», на Windows Git Bash (ставится вместе с git).

## Блоки урока
`text`, `why`, `trap`, `how` (два варианта шага: `terminal` и `vscode`; показывается
выбранный), `cmd` (команды с кнопкой «Копировать» и блок «Что вы увидите» с
реальными значениями ученика), `web` (шаги в интерфейсе GitHub с названиями
кнопок как в самом GitHub, на английском).

## Задачи
- `quiz` — как в остальных курсах.
- `steps` — список действий. У действия может быть проверка: ученик вставляет
  вывод команды, курс сверяет его с шаблонами (русский и английский вывод git).
  Если сверить не получилось, действие можно отметить вручную. Урок решён, когда
  отмечены все действия.

## Факты, сверенные с документацией
- Защита веток доступна в публичных репозиториях на бесплатном тарифе, в
  приватных нужен платный. Поэтому учебный репозиторий публичный, без секретов.
- По умолчанию защита не действует на администратора. Чтобы она работала для
  владельца, включается «Do not allow bypassing the above settings».
- GitHub умеет требовать pull request для `main`, но не умеет требовать, чтобы он
  шёл именно из `develop`. Это соглашение команды.
- Вход из терминала: GitHub CLI, `gh auth login` (GitHub.com → HTTPS → Yes →
  браузер). VS Code предлагает войти сам.
- Команда `git push origin develop:main` отклоняется защищённой веткой: так
  проверяем защиту, не создавая лишних коммитов в `main`.

## Открытые вопросы
- Скриншоты интерфейса GitHub и VS Code: пока уроки описывают кнопки словами.
  Блок `shot` добавим, когда появятся картинки.

## Что получилось в реализации
- Блоки: `text`, `why`, `trap`, `important`, `cmd`, `web`, `how`, `os`. Любой блок можно
  показать только для одного способа работы или системы: `only`.
- Отметки шагов запоминаются как номера (в облако уходят только они). Вставленный
  вывод хранится только на странице, потому что в нём могут быть имя и почта.
- Проверка вывода: шаблоны без учёта регистра с русскими и английскими вариантами.
  Каждый шаблон в уроках имеет образцы (`samples`), которые проверяет тест.
