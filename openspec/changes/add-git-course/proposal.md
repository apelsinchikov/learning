# Изменение: курс «Git и проект»

## Зачем
Системный аналитик всё чаще работает в репозитории: правит спецификации,
описания и тексты рядом с кодом. Для этого нужно понимать, что такое проект и git,
уметь клонировать репозиторий, делать коммиты, отправлять изменения и открывать
pull request. Многие работают без IDE, поэтому всё должно быть доступно и
через терминал, и через VS Code, на Mac и на Windows.

## Что меняется
- Новая вкладка и курс «Git и проект» (`#/git`): 5 глав, 13 уроков, открыт всем.
- Курс ведёт ученика по реальному пути: аккаунт GitHub, репозиторий с ветками
  `main` и `develop`, защита `main` (изменения только через pull request), клонирование,
  первый коммит, файл, `add` / `commit` / `push`, pull request из `develop` в `main`,
  чтение diff, слияние.
- Панель «Мой проект»: ученик один раз вводит логин GitHub, имя репозитория, имя и
  почту, а все команды в уроках показываются с его значениями.
- Переключатели «Mac / Windows» и «Терминал / VS Code»: шаги и сочетания клавиш
  показываются под выбранный вариант.
- Практика без запуска git в браузере: задания-шаги с проверкой вставленного
  вывода команды и тесты.
- Безопасность (двухфакторная защита, токены, секреты в репозитории) объясняется,
  но подробно не настраивается.

## Влияние
- Новые спецификации: `git-course`.
- Изменённые: `navigation-and-layout` (пятая вкладка, вкладки прокручиваются на
  узком экране), `progress-saving` (префикс `git-`).
- Данные: уроки `git-…` в `lesson_progress`, строка `course_state` с
  `course_id='git'`. Профиль «Мой проект» хранится только в браузере (там почта),
  в облако не отправляется. Новых таблиц нет.
- Код: `src/git/`, `src/courses/router.js`, `src/components/{CourseTabs,Header}.js`,
  `src/progress/cloudStore.js`, `src/main.js`, стили.
