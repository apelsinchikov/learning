# Изменение: практика PATCH и тело запроса для изменения

## Зачем
Урок 17 объясняет PUT и PATCH, но практика требует только PUT и DELETE, причём
PUT описывается без `requestBody` — хотя тело запроса изучено в уроке 9.
Различие, ради которого написан урок, не отрабатывается руками.

## Что меняется
- В практике «Update and Delete» добавить `PATCH /users/{id}` (200, 404).
- Для PUT и PATCH требовать `requestBody`: для PUT — все поля (`UserCreateRequest`),
  для PATCH — новая схема `UserUpdateRequest` без обязательных полей.
- Обновить текст задачи, проверку и итоговый урок 18.

## Влияние
- Затронутые спецификации: `practice-validation`.
- Мок-API уже поддерживает PATCH, менять его не нужно.
