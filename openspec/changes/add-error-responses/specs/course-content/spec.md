## ADDED Requirements

### Requirement: Описание ошибок
Курс SHALL содержать теоретический урок и практику, где ученик описывает ошибки
400 и 409 общей схемой `Error` и переиспользует ответ через `components/responses`.

#### Scenario: Итоговая спецификация
- **WHEN** ученик собирает итоговый Users API
- **THEN** у `POST /users` описаны ответы 400 и 409
