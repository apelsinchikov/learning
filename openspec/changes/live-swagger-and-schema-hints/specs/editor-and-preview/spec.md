## MODIFIED Requirements

### Requirement: Предпросмотр Swagger UI
Swagger UI SHALL строиться автоматически по YAML ученика, пока спецификация
валидна как OpenAPI, независимо от того, выполнено ли задание урока. Пересборка
SHALL выполняться с задержкой после последней правки (около 0,7 с), чтобы не
перерисовывать на каждый символ. Если спецификация невалидна, вместо Swagger
SHALL показываться список ошибок OpenAPI.

#### Scenario: Ученик пишет по ходу работы
- **WHEN** ученик правит YAML, и он остаётся валидным OpenAPI
- **THEN** Swagger обновляется и показывает текущее состояние, даже если условия задания ещё не выполнены

#### Scenario: Ошибка в OpenAPI
- **WHEN** в YAML ошибка (синтаксис, структура, парсер)
- **THEN** вместо Swagger показываются ошибки OpenAPI, а после исправления Swagger возвращается

#### Scenario: Try it out
- **WHEN** ученик в Swagger UI нажимает «Try it out» для пользовательских операций
- **THEN** запрос перехватывается мок-API и возвращает учебные данные

## ADDED Requirements

### Requirement: Широкая схема в Swagger
Блоки Schema и Example Value в ответах и теле запроса SHALL занимать всю ширину
панели Swagger. Узкая внутренняя рамка с собственной прокруткой SHALL NOT
использоваться для схемы.

#### Scenario: Просмотр схемы ответа
- **WHEN** ученик раскрывает ответ и открывает вкладку Schema
- **THEN** схема читается во всю ширину панели и не обрезается узким окном
