# Изменение: Swagger работает по ходу письма, схема шире, в практике есть пример и напоминание

## Зачем
Отзыв ученика по курсу OpenAPI:

1. **Практика 10 (Create User).** Ученик должен описать схему в `components`, но
   в блоке «Структура» показан только `POST`-эндпоинт со ссылкой `$ref`, а как
   выглядит сама схема — нет. В пояснении сказано «ты уже знаешь по прошлому
   уроку», но какому именно, не указано. Нужен пример и точное указание, где
   посмотреть (или сама нужная теория на месте, как в курсе SQL).
2. **Swagger.** Сейчас Swagger появляется, только когда решено задание И
   спецификация валидна. Из-за этого ученик не видит, что у него получилось по
   ходу работы. Нужно: Swagger строится всегда, когда OpenAPI написан верно;
   отдельная кнопка проверяет задание; Swagger остаётся на экране и после
   проверки.
3. **Ширина схемы.** В Swagger раздел Schema у ответа показывается в узком
   окошке; нужно шире.

4. **Стиль.** Курс OpenAPI выглядит жёстче остальных: острые углы и мелкий
   текст. Шрифт тот же (системный), разница в размерах и скруглениях.

## Что меняется
- **Живой Swagger.** При каждой правке (с задержкой около 0,7 с) YAML проверяется
  как OpenAPI (синтаксис, структура, парсер Scalar). Валидно — перерисовывается
  Swagger. Невалидно — вместо него список ошибок OpenAPI. Условия задания на
  отрисовку Swagger не влияют.
- **Кнопка «Проверить задание».** Проверяет только условия урока. Результат —
  баннер над Swagger: успех (урок отмечается решённым) или список невыполненных
  условий. Swagger при этом остаётся и не перерисовывается заново. Правка
  текста убирает баннер, но не снимает отметку «решено».
- **Широкая схема.** Блоки Schema и Example Value в ответах и в теле запроса
  занимают всю ширину панели Swagger, без узкой внутренней рамки.
- **Практика 10.** В «Структуру» добавлен пример `components → schemas`
  (для заказов, чтобы ответ не копировался один в один). Добавлен раскрывающийся
  блок «Напоминание из теории» с названием урока («Урок 7 · Схемы и
  свойства») и нужными фрагментами. Туманная фраза «по прошлому уроку» убрана.
- **Общее правило.** Практика, которая опирается на раньше пройденное, содержит
  такой блок. Данные: `theory.recall` у практики, рендер в левой панели.
  `theoryLinks`, которое не использовалось, остаётся только для служебных связей.

- **Единый вид с SQL и «Диаграммами».** Только CSS (новый `openapi-polish.css`).
  Основной текст 15–16px с интервалом 1.65 (было 13–14px), подписи не меньше
  11px (было 9–10px), таблицы 14px, кнопка «Проверить задание» 13px.
  Скругления: панели и карточки 14px, блоки кода 10px, кнопки 10px (было 6–10px).
  Колонки практики: Swagger шире остальных (1 : 1 : 1,3).
  Блоки ошибок и успеха проверки оформлены как карточки.

## Не входит
- Подсветка уже выполненных частей задания по ходу письма (может быть следующим шагом).
- Перенос панели «Повторить» из SQL-курса в OpenAPI (у OpenAPI другая раскладка из трёх колонок).
